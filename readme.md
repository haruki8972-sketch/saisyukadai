# ASCIIスキーゲーム（`w11_ski_demo.py`）

ターミナル（`curses`）上で動作するASCIIアート形式のスキーゲームです。左右の旋回を切り替えながら崖（`*`）や木（`A`）を避け、コイン（`@`）を集めてハイスコアを目指します。

---

## ゲームの概要

コースが上から下へスクロールする中、プレイヤー（`O`／ゲームオーバー時は`X`）を操作して障害物を回避するアクションゲームです。

### 主な特徴
* **直進不可の旋回操作**：進行方向は常に「左（`-1`）」または「右（`+1`）」の二択で、1行進むごとに左右どちらかへ1文字分移動し続けます。
* **レベル制による難易度上昇**：コースが60行進むごとにレベル（`LV`）が1上がり、スクロール速度（`SPEED`）や木（`A`）の出現率が上昇し、コース幅も段階的に狭まります。
* **コインとコンボシステム**：コース上のコイン（`@`）を取得すると `100 × コンボ数` のスコアを獲得できます。連続取得でコンボ（`combo`）が伸び、外れるとリセットされます。
* **ターミナルサイズへの自動対応**：ウィンドウサイズ変更を検知してフィールドサイズを再計算します。最小サイズ（`64×21`）未満の場合はリサイズを促す画面を表示します。

---

## 動作環境

* **OS**：Windows / macOS / Linux（端末エミュレータ・VS Code ターミナルなど `curses` が動作する環境）
* **言語**：Python 3.x（標準ライブラリの `random`、`time`、`collections`、`curses` を使用）
* **追加ライブラリ（Windowsのみ）**：`windows-curses`
* **最小ターミナルサイズ**：幅 `64` 列 × 高さ `21` 行以上（フィールド最大幅 `68` 文字）

---

## インストール方法

macOS / Linux では Python 標準の `curses` が利用できるため、原則追加インストールは不要です。Windows 環境で `curses` が見つからない場合は、コマンドプロンプトや PowerShell で以下を実行してください。

```bash
py -m pip install windows-curses
```

## 起動方法

`w11_ski_demo.py` があるディレクトリに移動し、以下のコマンドで起動します。

```bash
python w11_ski_demo.py
```

※ Windows で `python` コマンドが反応しない場合は `py w11_ski_demo.py` を試してください。

## 操作方法

### キー操作

| キー | 動作 |
| :--- | :--- |
| `SPACE` | ゲーム開始（`READY` 時）／ 一時停止・再開（`PLAYING` ⇔ `PAUSED`） |
| `←`（左矢印） | 進行方向を左（`-1`）に切り替える（`PLAYING` 中） |
| `→`（右矢印） | 進行方向を右（`+1`）に切り替える（`PLAYING` 中） |
| `R` | リスタート（`GAME_OVER` 時のみ有効） |
| `Q` / `q` | ゲーム終了 |

### ゲームルールと画面表示の見方

* **プレイヤー**：`O`（衝突・崖落下時は `X`）
* **崖**：`*`（触れると `CLIFF!` でゲームオーバー）
* **木**：`A`（触れると `TREE!` でゲームオーバー）
* **コイン**：`@`（通過すると取得し、スコア加算＋コンボ継続）
* **ステータスバー（1〜2行目）**：`LV`（レベル）、`SCORE`（スコア）、`DIST`（進んだ行数）、`TIME`（経過時間）、`SPEED`（速度倍率）、`TURN`（現在の旋回方向）、`STATE`（ゲーム状態）

## 追加・改良した機能

提示されたコード（第11回配布教材・学生版）および実装内容に基づく主なポイントは以下の通りです。

* **`update_distance_score(state)` の実装**：コースが1行進むごとに呼び出され、`state["score"]` を `+1` 加算するように実装されています。
* **コイン取得時のコンボ・スコア加算と消去**：`check_collision(state)` にてコイン位置（`row["coin"]`）に到達した際、`combo` を増やして `100 * combo` を `score` に加算し、取得済みのコインを `None` にして二重取得を防いでいます。
* **コース生成（`create_course_row`）**：レベルに応じたコース半幅の縮小や木の出現率上昇、一定間隔（`min_coin_interval = 15` 行）をあけたコイン配置などの生成ロジックが含まれています。

## 既知の問題・制限事項

* **VS Code 等の IDE 組み込みターミナルでの表示制限**：環境によっては `curses` の初期化や画面描画に失敗することがあります。その場合は外部ターミナルや別の端末で実行し、ウィンドウ幅・高さを `64×21` 以上に広げてください。
* **一時停止中（`PAUSED`）のリスタート非対応**：`R` キーによるリスタートは `GAME_OVER` 状態でのみ有効です。プレイ中や一時停止中にやり直す場合は `Q` で終了して再起動する必要があります。
* **`update_distance_score()` の条件式**：`if state["scroll_count"] + 1:` は `scroll_count` が `0` でも `0 + 1 = 1`（真偽値で `True`）となるため実質無条件で `score += 1` となります。1行進むごとに1点加算する仕様であれば問題なく動作しますが、条件分岐を意図していた場合は見直しが必要です。
* **画面リサイズ時の状態リセット**：実行中にターミナルのサイズを変更すると、現在の `state` が再生成され初期状態（`READY`）に戻ります。
